## What changes

- **`candy/plugin-check/unresolved_classifier.go`** (new) — `declaredVarNames(rp)` builds the project's declared variable vocabulary from `rp.CandyModels[*].Vars` ∪ `[*].Env.Vars`; `installUnresolvedClassifier(runner, declared)` installs the closure. **One-sided by design:** a name *some* candy declares is `UnresolvedConditional`, because a candy composes into deployments its own manifest cannot see — narrowing per candy would turn a legitimate skip into a false dead-assertion failure, which is the one error this must not make. A name nothing declares is `UnresolvedUnknown`.
- **`candy/plugin-check/plugin_runner.go`** — `newPluginCheckRunner` takes a **required** `declared map[string]bool` and installs the classifier before returning, so every construction site gets it by construction and none can forget.
