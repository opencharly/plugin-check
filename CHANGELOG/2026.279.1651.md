# 2026.279.1651 — fix(diagnostics): add the cachyos-xz-local-newer-than-repo allowance

## Summary

`plugin-check`'s log-diagnostic allowlist carries the CachyOS "local build newer than
the repo" upstream-skew entries for `zstd`, `pacman-contrib`, `binutils` and `libtool`
— but not **`xz`**, which is the SAME class, reported in the SAME pacman transaction.
Its warnings therefore survived the gate, so a cachyos box's `deploy-add`/`update` step
was **not at zero warnings**.

This adds `cachyos-xz-local-newer-than-repo` (the same regexp/`Why` shape as the four
existing entries) and its pin in `bed_diagnostics_test.go`. The documented
one-package-per-entry pattern is deliberate (each exemption is a separately reviewed
diff); this is the fifth such package.

Closes #79.

### Addressing the round-1 BLOCK

**#1 (B12 — self-contradicting evidence).** My earlier paste showed one example line
per package and read as one survivor; the step counter said 3. Reconciled with the real
per-package occurrence counts below: the step log carries **12** `newer than` warnings
(3 each for binutils, libtool, xz, zstd); 9 were allowlisted and the **3 `xz`**
occurrences survived — which is exactly the step's `warnings=3`. **#2 (A3 — tier).** The
changed entry now provably executes live: the POST-FIX VM bed is pasted below at
