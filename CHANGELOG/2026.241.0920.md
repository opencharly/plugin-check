# 2026.241.0920 — fix(check): allowlist the dev/worktree binary notice

## Summary

A dev/worktree charly binary (the in-development build every charly check bed installs via the `charly-dev` candy) is not at the FHS location that owns `/usr/lib/charly/plugins`, so it deliberately skips the installed package's plugins (built against a different charly version, issue #328) and says so once per process. Every `check-charly-vm` step log carries this line when the host has a packaged charly install, so the bed reported `warnings=11` instead of `warnings=0`.

Add a `dev-worktree-binary-notice` allowance matching the informational dev-build line.
