# 2026.295.2128 — fix(check): tear down a kind:local bed in place, never with the container verb

## Summary

`charly check run` on a `host: local` bed (`kind:local`, host-rooted) tore the venue down with the **container** verb `charly remove --purge` in both cleanup switches. Each switch tested `d.IsExternal` only, so `d.IsLocal` fell through into the pod arm. A local venue applies candies to a host filesystem and need not have a container engine, so the teardown exited 1 (`no container engine found (install podman or docker)`) — and because the success path fails the bed on a cleanup failure, every host-venue bed was impossible to pass. The arm is reached only after every authored assertion passes, which is why `charly box validate` cannot catch it (opencharly/plugin-check#129: live run of `check-k3s-shared-containerd` printed `4 steps: 4 passed, 0 failed, 0 skipped`, then `[cleanup] FAIL`, `FAIL (steps=6)`, `summary.yml ok: false, errors: 1`).

The failure-path retention hint repeated the wrong verb for the same venue (`destroy: charly remove <bed>`).

This PR:

- Adds ONE predicate `bedInPlace(d)` (local OR external) and ONE root-teardown argv owner `bedRootTeardownArgs(d, name, isKubeVirt)`. The pre-run cleanup, the final `cleanup` switch and the `isInPlace` bring-up gate all read them, so the bring-up and teardown halves cannot drift (R2 — three sites collapsed to one).
- Kubevirt roots and both in-place venues (local + external) tear down with `charly deploy del`; a container pod keeps `remove --purge`, the only path that reaches `purgeDeployArtifacts` (named volumes, gocryptfs volumes, synthesized `<name>-overlay` images). The VM keeps its `vm destroy` arm (domain/disk flags).
- The local debug hint now prints `destroy: charly deploy del <bed>`.

### Sibling sites checked

- `bed_run.go` pre-run cleanup switch — was `if d.IsExternal { deploy del } else { remove --purge }`; now the shared helper.
- `bed_run.go` final `cleanup` switch — was `case d.IsExternal` plus a pod `default`; now the shared helper.
- `bed_run.go` `isInPlace := d.IsLocal || d.IsExternal` — the third copy of the predicate; now `bedInPlace(d)`.
- `bed_run.go` `printDebugRetentionNotice` local arm — wrong verb; corrected.
- `instrument.go` `venueKindOf` — classifies the venue (vm/local/external/pod), not a teardown decision; unchanged.
- `bed_persist.go` — passes `d.IsExternal` as `externalInPlace` to `PersistBedDeployOverrides`; a host-rooted node self-skips inside deploykit, so this is not a teardown decision; unchanged.
- `stop_cmd.go` `pod: charly remove` — the pod hint, correct as printed; unchanged.
