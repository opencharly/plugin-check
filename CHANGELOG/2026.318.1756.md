# 2026.318.1756 — fix(check): the vm collectors stop naming the deleted authored type

## Summary

opencharly/spec#304 unit 8: the vm body moved into plugin-substrate CUE module and the contract leg deletes `spec.Vm`. Two collectors in this repo still decoded it, and the assembled build named both:

- `checkproject.go` - the check project plan reader: it now decodes the resolve envelope (`spec.ResolvedVm`), which carries the same `plan` field;
- `live_gather.go` - the mcp_provide collector: `mcp_provide` is the AUTHORED body own field that the envelope deliberately does not carry, so the decode names exactly that one field in a local struct.

Neither is a behaviour change: the plan field and the mcp_provide field keep their names and JSON tags, and the collector reads the same values.

**Found by the assembled build**, which is why that build runs before the contract leg: the plugin suite alone was green because this repo pins a spec that still declares `spec.Vm`.
