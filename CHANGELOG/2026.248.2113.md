# 2026.248.2113 — fix(check): detached recorder survives the caller ctx + evidence threads the pipeline source

## Summary

RCA (live, check-instrument-cachyos-vm): every instrument-bed recorder died at spawn with an empty recorder.log and no evidence row. The reverse-leg InvokeProvider that dispatches the verb:session seam wraps its ctx with a timeout + defer cancel() — the cancel fires the moment the spawn call returns, and spawnSetsidProcess's exec.CommandContext SIGKILLed the just-spawned recorder before it ever dialed. The recorder is DETACHED by design (setsid + pidfile, the handle is the liveness key); the ctx bounds nothing.

- spawnSetsidProcess: exec.Command (not CommandContext) — the process lifetime is owned by the handle + the stop ladder, never the caller's ctx.
- spawnSetsidProcess: retain the recorder's stderr to <state_dir>/recorder.log so a recorder that exits without its end-of-stream artifact is diagnosable (R1: the failure must be visible, not a silent "evidence row missing"). The parent's fd copy is closed after Start() (the child inherited its own reference at fork — B18).
- evidence phase: thread the entry's primary artifact under source_artifact (the transcode verb's source contract) alongside the generic artifact key — the check env is fixed at runner construction and cannot carry a per-entry path, so the op input is the only channel.
