# 2026.268.0055 — feat(check): add kind:check-roster — run a declared bed set as one gate

## Summary of changes

Add `kind: check-roster` to candy/plugin-check — the config-declared, plugin-native roster that runs a declared set of disposable check beds together (in parallel) as one gate. Replaces the `/verify-beds` agent-workflow fan-out.

- `schema/checkroster.cue` — the self-contained `#CheckRosterInput` CUE def (select glob, exclude, expected_fail, lanes, cpu/ram, refuse_host_local, var). FLAT kind.
- `roster_helpers.go` (NEW) — host-free helpers: `numCPU()` and `isRosterEntity()` (routes `charly check run <name>` to the roster path).
- `roster.go` — the runner: loads the project plugin-side (`loaderkit`), enumerates beds via the ONE namespace-aware resolver (`spec.UnifiedFile.Beds()`), selects/excludes by qualified-name glob, classifies (runnable / expected_fail / iterate-excluded / host-local-refused), **auto-derives exclusive-token serial chains by UNION-MERGING every chain a bed's token set touches** (two chains never share a token), runs the rest through the EXISTING R10 engine (`runCheckBed`) on a bounded `lanes` pool, threads the roster's `cpu`/`ram` to `charly vm create --cpus/--ram`, and aggregates honest exit codes (0 pass / 1 infra / 2 checks-failed / 3 all-skipped). Negative controls pass when they fail on checks (exit 2).
- `plugin.go` / `provider.go` — advertise the `check-roster` kind (+ `schemaFS` embed); handle `OpLoad`, caching the RESOLVED body in a **mutex-guarded** `rosterCache` (the pipeline `entityCache` precedent).
- `run_cmd.go` — a `check-roster` entity name routes to `runCheckRoster`; the `/verify-beds` redirect is DELETED.
- `bed_run.go` — `bedRunOpts` gains `Cpus`/`Ram` (the roster-enforced VM shape), threaded to `vmCreateArgs`.
- `anchored.go` — `vmCreateArgs` appends `--cpus`/`--ram` from `bedRunOpts`.
- `bed_session.go` — use the one resolver (`uf.ResolveBed`) and qualify a namespaced bed's bare `from:` with its namespace prefix.
- `roster_test.go` — unit coverage: selection, host-local refusal, iterate exclusion, globs, serial chains (incl. union-merge), expected-fail, exit aggregation (incl. all-skipped), balanced WaitGroup accounting; `anchored_test.go` covers the capped vm-create argv.
- `go.mod`/`go.sum` — pin `spec` `v0.2026267.2224` + `sdk` `v0.2026267.2238` (merged namespace fixes); adds the `opencontainers/go-digest` + `opencontainers/image-spec` indirects transitively.
