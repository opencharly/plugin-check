# 2026.243.0857 — feat(check): add check plan - resolve and print a box's check plan as JSON

## Summary

Add `charly check plan <image>` — resolve a box's check plan and print it as JSON WITHOUT running it.

Why: the check pipeline resolves plans internally (ExtractMetadata → ResolveCheckVarsBuild) and only then executes, but NO command exposed the resolved plan. Diagnosing a failing check (`layer-direnv:2` file exists=false) required digging the resolved plan out of build logs with ad-hoc scripts — a genuine command gap. This leaf reuses the SAME resolve phase the box arm uses (`pluginCheckRunBox` minus `RunPlan`) and emits `{image, env, steps}` as JSON.

**Changes (5 files):**
- `plan_cmd.go` — `CheckPlanCmd` kong leaf + `pluginCheckRunPlan` (resolve-only mirror of `pluginCheckRunBox`).
- `check_cmd.go` — register the `plan` leaf in the `CheckCmd` tree.
- `command.go` — `case "plan"` in `hostCheckRunCtx`.
- `plan_cmd_test.go` — JSON shape (unit).
- `plan_resolve_test.go` — integration: exercises the REAL resolve path (ResolveRuntime → ResolveBuiltImageRef → ExtractMetadata → ResolveCheckVarsBuild → pluginResolverEnv) against a locally-built image; skips only when no image exists on a fresh runner.
