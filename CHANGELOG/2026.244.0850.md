# 2026.244.0850 — feat(check): the feature-live ADE path supports VM deployments

## Summary

The feature-live path (`charly check feature run`) was container-only: it called `deploykit.ResolveContainer` directly, so ADE grading of a VM deployment's plan failed with `container ... is not running`. The check-live path already classifies the target and dispatches to per-kind gathers (`pluginCheckLiveVM` etc.); the feature-live path never did.

Fix: classify the target (`featureLiveArm` — extracted for testability) and dispatch to a pod arm (the existing container path, unchanged) or a new VM arm (`pluginCheckRunFeatureLiveVM`) that mirrors `pluginCheckLiveVM`'s SSH-venue construction — the SSH executor, the runtime-vars env, the VM plan gather, the `HostVars` + `TargetResolver` (the venue resolver the out-of-process wl plugin needs to reach the VM's compositor) — plus the ADE grader wiring (`resolveAgentSpec` + `AgentGrader`) and `SkipDeterministicRun` (feature-run semantics).
