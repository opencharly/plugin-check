# 2026.239.2017 — fix(check): allowlist pacman .pacnew config-file notices

## Summary

pacman's standard `.pacnew` safety mechanism emits `warning: <file> installed as <file>.pacnew` when a package's config file differs from the previously-installed version during a transaction. Every pacstrap bootstrap VM `deploy-add` (guest-side `pacman -Syu` updating `locale.gen` and the `tpm2-tss` fapi profiles on a freshly-pulled base) surfaces 3 such warnings; they are informational, deliberate pacman behavior — not errors.

**Fix:** add a `pacman-pacnew-config-notice` diagnostic allowance, scoped to the exact `installed as ...pacnew` sentence, so the bed gate shows `warnings=0` for this benign class (mirroring the existing `mkinitcpio-chroot-warnings` allowance).
